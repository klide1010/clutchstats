# BKStats Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA offline-first per statistiche live di basket, con Worker Cloudflare per login, sync e API di lettura.

**Architecture:** Monorepo npm workspaces con `shared/` (tipi e funzioni pure), `app/` (Preact + Vite, IndexedDB) e `worker/` (Cloudflare Worker + D1). La partita è una lista di eventi immutabili; box score, minuti e punteggio sono sempre derivati dagli eventi. La sync è push/pull con last-write-wins su `updatedAt`.

**Tech Stack:** TypeScript, Preact 10 + `@preact/signals`, Vite 6, `vite-plugin-pwa`, `idb`, Vitest, `fake-indexeddb`, Hono, Cloudflare Workers + D1, wrangler 4, `@cloudflare/vitest-pool-workers`.

**Spec:** `docs/superpowers/specs/2026-10-06-bkstats-design.md`

## Global Constraints

- Target browser Chrome Android ≥ 70: Vite `build.target: 'es2018'`, niente top-level await, niente `crypto.randomUUID` (usare `newId()` di `shared/`), niente `Array.prototype.at` in `app/src` e `shared/src` (nei test va bene).
- Bundle JS dell'app < 100 KB gzip totale. Nessuna libreria UI, nessun CSS framework.
- Testi UI in italiano. Ruoli mostrati come: Play, Guardia, Ala, Ala grande, Centro.
- Ogni record ha `id` (UUID v4 generato dal client), `updatedAt` (ms epoch), `deleted` (boolean).
- Ogni scrittura locale va in IndexedDB prima di aggiornare la UI.
- Il Worker non logga mai password né token.
- Commit frequenti, messaggi in inglese con prefisso `feat:`, `test:`, `chore:`, `docs:`. Ogni commit termina con `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Autore git: `-c user.name="Andrea Dali" -c user.email="andrea.dali@soluzione1.it"` se la config globale manca.

### Task 3: Tempo di gioco e minuti giocati

**Files:**
- Create: `shared/src/time.ts`, `shared/src/minutes.ts`, `shared/test/minutes.test.ts`, `shared/test/fixtures.ts`

**Interfaces:**
- Produces (`time.ts`): `periodLengthSec(game: Pick<Game,'periodLengthMin'|'periodsRegulation'>, period: number): number` (regolamentare = `periodLengthMin*60`, supplementari = 300); `elapsedSec(game, period, clockSec?: number): number` = somma periodi precedenti + (lunghezza periodo − clockSec); se `clockSec` è undefined restituisce la metà del periodo.
- Produces (`minutes.ts`): `computeSecondsPlayed(game: Game, events: GameEvent[], nowElapsedSec?: number): Record<string, number>`; `onCourtAfter(game: Game, events: GameEvent[], uptoSeq: number): string[]`.

Regole: gli eventi `deleted` sono ignorati. In campo all'inizio = `game.starters`. `SUBSTITUTION` rimuove `subOutPlayerId` e aggiunge `subInPlayerId` al tempo `elapsedSec(game, period, clockSec)`. `PERIOD_END` chiude gli intervalli al termine del periodo; `PERIOD_START` del periodo successivo li riapre per gli stessi giocatori. Se l'ultimo periodo è aperto e `nowElapsedSec` è dato, gli intervalli aperti si chiudono lì; altrimenti si chiudono all'ultimo evento con tempo noto del periodo.

### Task 4: Box score e valutazione Lega

**Files:**
- Create: `shared/src/boxscore.ts`, `shared/src/rating.ts`, `shared/test/boxscore.test.ts`, `shared/test/rating.test.ts`

**Interfaces:**
- Produces (`boxscore.ts`):

```ts
export interface StatLine { pts: number; fg2m: number; fg2a: number; fg3m: number; fg3a: number; ftm: number; fta: number; oreb: number; dreb: number; reb: number; ast: number; tov: number; stl: number; blk: number; blkR: number; pf: number; pfd: number; screens: number }
export interface PlayerLine extends StatLine { playerId: string; seconds: number; plusMinus: number; rating: number }
export interface TeamLine extends StatLine { foulsByPeriod: Record<number, number>; timeouts: number }
export interface OpponentLine extends TeamLine { foulsByJersey: Record<number, number>; pointsByJersey: Record<number, number> }
export interface BoxScore { players: PlayerLine[]; team: TeamLine; opponent: OpponentLine; score: { us: number; them: number }; scoreByPeriod: { period: number; us: number; them: number }[] }
export function emptyStatLine(): StatLine;
export function computeBoxScore(game: Game, events: GameEvent[], players: Player[], nowElapsedSec?: number): BoxScore;
```

- Produces (`rating.ts`): `legaRating(l: StatLine): number` = `(pts + reb + ast + stl + blk + pfd) − ((fta−ftm) + (fg2a−fg2m) + (fg3a−fg3m) + tov + blkR + pf)`.

Regole: `players` in output = tutti i `players` passati con `teamId === game.teamId` più eventuali `playerId` presenti negli eventi, ordinati per numero. L'assist si conta a `assistPlayerId` dei tiri segnati (`SHOT_2`, `SHOT_3`, non `FREE_THROW`). `FOUL` lato US conta `pf` del giocatore e `foulsByPeriod[period]` della squadra per ogni `foulKind`, tecnici inclusi. `FOUL` lato THEM conta `opponent.foulsByJersey[jerseyNumber]` se presente e `opponent.foulsByPeriod`. `pointsByJersey` come i falli. Plus/minus: a ogni tiro segnato, ±valore per i giocatori in campo (tracciati con la stessa logica di `onCourtAfter`). `seconds` da `computeSecondsPlayed`. `rating` da `legaRating`. `scoreByPeriod` ha una riga per ogni periodo con almeno un evento.
